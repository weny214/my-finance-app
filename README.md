# my-finance-app｜個人理財與目標管理網站
這是一個專為日常收支記錄與儲蓄目標管理所設計的輕量級網頁應用程式。採用純前端技術開發，不需要繁瑣的後端設定或資料庫，所有資料皆安全地保存在使用者的瀏覽器本地端（`localStorage`）。
這是一個免登入、資料存於瀏覽器的個人理財與目標管理網頁。透過奶油白溫潤視覺與響應式單雙欄介面，提供本月收支統計、明細增刪、月份篩選、圖表佔比、理財小提醒與儲蓄目標進度追蹤功能。本作品以 HTML、CSS 與 JavaScript 實作，完整符合單一檔案規格，讓使用者能直覺、無負擔地管理日常財務。
## 主要功能特色
1. ** 財務總覽儀表板**
   * 自動計算並顯示所選月份的**總收入**、**總支出**、**本月結餘**。
   * 即時呈現所有儲蓄目標的整體平均完成率。
2. ** 靈活的收支紀錄**
   * 支援「收入」與「支出」切換。
   * 提供多種分類（如：飲食、交通、購物、薪資等）與自訂備註、日期填寫。
   * 支援單筆紀錄刪除及整月清空功能。
3. ** 月份篩選器**
   * 可自由切換不同月份，查看歷史收支明細與當月統計數據。
4. ** 儲蓄目標管理**
   * 可自訂多個儲蓄目標（如：緊急預備金、旅行基金），設定目標金額與已存金額。
   * 具備「快速存入」功能，隨時更新存款進度條與剩餘金額。
5. ** 智慧理財小提醒**
   * 根據當月的收支狀況自動生成貼心提示與消費佔比分析。
6. ** 響應式介面設計（RWD）**
   * 支援電腦版雙欄佈局與手機單欄瀏覽，隨時隨地都能輕鬆記帳。

##  技術規格

* **前端架構**：HTML5, CSS3 (CSS Variables, Flexbox/Grid)
* **互動邏輯**：Vanilla JavaScript (ES6+)
* **資料儲存**：瀏覽器 `localStorage`（無須後端伺服器）
* **樣式風格**：奶油白（`#f7f4ef`）、奶咖色系與低飽和配色，提供舒適的視覺體驗。
